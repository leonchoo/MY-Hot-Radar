## 4. 新增规则摘要（docs/LOCAL_NEWS_EDITORIAL_RULES.md）

- **A 本地新闻范围与选题**：以柔佛/新山、全国性政策/经济/教育/交通/民生/公共安全、华人社区及读者实际相关事件为优先；不因「发生在柔佛或涉及华人」自动认定高价值；按真实性、公众利益、影响范围、时效性、完整程度、独立价值综合判断；不得夸大普通事件。
- **B 马来西亚中文来源纳入发现流程**：《星洲日报》《中国报》《光明日报》《东方日报》《光华日报》等为发现清单（非可信度认证）；每篇仍须核实际文章、日期、原始出处；找不到中文报道须如实记录，不得虚构或错挂中文媒体。
- **C 跨语言搜索与重复新闻识别**：同一事件的中/马/英报道须按人物、地点、日期、数字、公告编号比对；转载/翻译/同一新闻稿不算独立来源；多家引用同一官方声明记作共同原始来源。
- **D 来源优先级与事实核查**：官方公告→执法/司法→当事方声明→有编辑责任媒体→可追溯原始资料；优先级非机械排名；区分已确认/官方说法/媒体未独立证实/指控与推测/未确认；刑案区分被调查/逮捕/被控/定罪；重点核对日期、数字、单位、币种、发布主体；社媒传闻不得直接写成事实。
- **E 标题和中文表达**：标题须准确反映正文；禁止制造恐慌、夸大、猜测写成事实、「全网疯传/震惊全马」式无据概括、普通事件包装成危机、误导性时间地点人物；准确性优先于点击率；大白话解释本地机构/政策/地名。
- **F 实质价值**：不止复制新闻稿或简单换中文；解释事件要素、时间线、已确认事实、数字含义、机构行动、对读者影响、待确认事项；证据不足如实说明，不猜填补；不空泛凑字数。
- **G 评论/网友/社媒**：仅在有真实可追溯来源时才能呈现；禁止虚构留言、评论区热议、采访、引述、投票、普遍反应；「不少网友表示」须有足够证据；作者分析不得伪装成网友意见；引用保留语境。
- **H 时效与更新**：区分事件发生/首次公布/媒体报道/文章发布/实际更新时间；禁止改日期或「今天/刚刚/最新」误导；旧闻因新进展重报道须交代时间与更新原因；更新须核实新信息。
- **I 发布前检查**：标题正文一致、人物/地点/日期/数字准确、来源真实可访问且支持说法、三语无明显冲突、无虚构评论、实质信息、不重复发布、分类/摘要/时间/链接正确；关键事实存疑不得以「已写好」为由发布。
- **J 发布后验证**：详情页正文、分类页标题摘要链接、首页/索引同步、sitemap/canonical、无旧标题/旧摘要/占位残留；必须检查真实线上响应，不得以构建成功/200/commit-push 代替；逐项 PASS/FAIL/UNKNOWN。
- **与国际规则关系**：共用七条底线（不编造、不将未证实写成事实、不转载冒充独立核实、不夸大标题、不以字数替代价值、保留可追溯来源、发布后真实验证）；本地额外强调中文媒体发现、三语交叉核实、本地机构/政策/地名准确、对读者实际相关性；国际规则不因本地规则削弱。
