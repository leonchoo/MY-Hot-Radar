The basic rules for using this site. The current version is a static MVP, so most of these terms describe what the site does not yet do.

Last updated: 28 September 2026 · MVP stage

1. About these terms

MY Hot Radar is currently in MVP / demonstration stage. These terms describe how you may use the site as it exists today. As features are added (news content, accounts, comments, advertising, etc.), these terms will be updated.

2. Website content

Every story, headline, description, category label, status badge, and "radar indicator" shown on this site is currently sample / demo content. It has been created for layout testing, not to report real events.

Sample content should not be treated as factual reporting, real news, or a description of any actual person, brand, place, or event.

3. No news accuracy guarantee

The current MVP does not represent a live news reporting service. It does not perform real-time monitoring, does not verify sources, and does not provide journalism. Any resemblance between a sample headline and a real story is incidental and unintended.

When MY Hot Radar moves beyond MVP, content policies will be updated to cover source attribution, corrections, takedown requests, and how the site separates sample material from real reporting. Those updates will be reflected here.

The site is provided as-is and may be modified, paused, or discontinued at any time. There is no guarantee of continuous availability, and no SLA is offered during the MVP stage.

7. Acceptable use

While using the site you agree not to:

  • Misrepresent sample content as real news from MY Hot Radar

8. Changes to these terms

These terms may be updated as the site grows. The "Last updated" date at the top will reflect the most recent revision. Material changes that affect how the site handles user content or personal data will be highlighted when they happen.

Contact details will be published when the service officially launches. Until then, please refer to the About page for context on the current stage of the project.
